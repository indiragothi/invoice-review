# Samples

Ground-truth documents for evaluation. See [../docs/evaluation.md](../docs/evaluation.md) for the plan (36+ documents) and the `manifest.json` format.

Only fictional, synthetic, fully redacted or properly licensed documents belong here. Never commit real client bills.

`manifest.json` is the evaluation contract: expected type, field values, status and error codes per document. It is filled in as documents are generated.
